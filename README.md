# Tip Calculator

A simple Python program that asks the user for a bill amount and a tip percentage. It calculates the tip and the total bill, then displays both amounts to two decimal places.

## Requirements

- Python 3

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

## Example Run

```text
Enter the bill amount: KSh 1000
Enter the tip percentage: 10

Tip: KSh 100.00
Total bill: KSh 1100.00
```

If the user enters text instead of a number, the program displays a friendly error message. It also checks that the bill and tip percentage are not negative.

## Skills Practised

- Python input and output
- Arithmetic calculations
- `try` and `except` error handling
- Formatting numbers to two decimal places
